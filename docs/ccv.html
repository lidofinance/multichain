CCV configuration

Each pool's hooks configure one resolver in the required inbound/outbound CCV set. It resolves to this deployment's DummyMessageIdVerifier. This checks a message ID, not an independent security attestation. The fork scenarios separately exercise a two-verifier quorum; that test configuration is not the public deployment's configured pool set. Lane-mandated verifiers and transport state must be read from the current ramps; the pool set alone does not establish them.
