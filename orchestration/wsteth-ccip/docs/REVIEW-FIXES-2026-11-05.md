# Исправления замечаний перед коммитом — 2026-11-05

Исправлены пять замечаний последнего ревью рабочего дерева. Публичный деплой
Sepolia / Base Sepolia / Mantle Sepolia не передеплоен; публичные транзакции
при этой работе не отправлялись. Миграционные L1/L2 bridge implementations
относятся к будущей миграции существующего Base-моста и не входят в этот
публичный scratch deployment. `components/ccip` остался чистым на закреплённом
gitlink `07ae438b0028f14d1ccce9072e3f53b8b14e8a09`.

## Что изменилось

1. `ccip_build.py` записывает только разрешённые параметры компилятора вместо
   полного `forge config --json`. Explorer/API credentials больше не попадают
   в новые build records. Очищены десять исторических JSON в research evidence;
   [примечание об изменившихся хешах](../../../runs/wsteth-2.0/research/upstream-isolation-20261104/README.md)
   отделяет очищенные записи от первоначального доказательства сборки.
2. Атомарный Base action set назначает L2MigrationBridge policy engine для
   hooks пула. Все исходящие вызовы пула, включая прямой Router, отклоняются до
   успешного `activate()` на Base. Выдача BURNER_ROLE и регистрация пула на T_vote_L1
   больше не позволяют обойти условие активации.
3. L1 `activate()` атомарно переносит обеспечение в lockbox и отправляет
   `confirmL1Activation()` через канонический messenger. Base принимает
   подтверждение только от этого messenger с адресом L1-моста как cross-domain
   sender. Без подтверждения активация отклоняется, даже после наступления
   таймера. Неудачную доставку можно повторить. StateMate, сценарии миграции,
   CCV-тесты, runbook и локальный HTML Explainer приведены к этому порядку.
4. Smoke `run`/`advance` восстанавливают отсутствующие записи сообщений из
   сохранённых транзакций до проверки балансов. Поиск исполнения начинается с
   исходного блока baseline, поэтому новый preflight после сбоя не скрывает
   перевод, уже исполненный в целевой сети. Повторная отправка не требуется.
5. Проверка паузы старого HubPool принимает только точные revert data
   `TokenMaxCapacityExceeded(2, amount, token)`. Ошибки RPC, отсутствие revert
   data и другие ошибки останавливают прогон. Тестовый баланс и allowance
   задаются через временные `eth_call` overrides, без изменения storage форка.
