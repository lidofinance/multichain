    Модель начинается с балансов на 11.11.2026; суммы переводов D1–C2 и моменты их завершения выбраны для иллюстрации. W0 представляет разницу исходного эскроу и количества wstETH на Base, а не список восстановленных сообщений; сами сообщения перечислены в таблице «Legacy-переводы в полёте» шага 0. Старый депозит Ethereum → Base обычно доставляется за минуты. Для вывода Base → Ethereum минимальное ожидание после prove — сутки при быстром пути AggregateVerifier с двумя доказательствами, TEE и ZK; оценка обычного срока около 5 суток ещё не проверена. Параметры OptimismPortal2 приведены на 11.11.2026. Доставка CCIP условно занимает десятки минут; работу сети операторов Chainlink (DON) модель не воспроизводит.
    На каждом шаге проверяется равенство: эскроу моста L1 + баланс BaseLockBox − количество wstETH на Base = сумма незавершённых переводов. Отдельно показано обеспечение пяти прежних направлений: 18 306,4 wstETH на блоке 26 391 413. На шаге 1a оно переходит из пула Chainlink в четыре других lockbox; переводы по этим направлениям модель не рассчитывает.
